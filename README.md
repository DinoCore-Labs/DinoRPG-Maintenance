# DinoRPG Maintenance — Page de maintenance statique pour DinoRPG Remastered

## Identité reprise du jeu

- `HomePage.vue` affiche `background_beta.webp` dans `.homepage-banner` : le logo DINO RPG BETA, l'île et ses nuages sont ceux de l'application, **pas une reproduction**.
- `MaintenancePage.vue` : couleurs `#8f4f2e`, `#ffee92`, `#fce3bc`, `#3b2115` et textes de maintenance originaux.
- `Footer.vue` : `4dinoz.webp` et `sky_footer.webp`.
- `TopBar.vue` : bandeau sombre.
- Quatre langues : FR / EN / ES / DE
